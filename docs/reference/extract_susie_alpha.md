# extract the alpha matrix from susie result adapted from susie's susie\_get\_pip() function

extract the alpha matrix from susie result adapted from susie's
susie\_get\_pip() function

## Usage

``` r
extract_susie_alpha(susie_res, prune_by_cs = FALSE)
```

## Arguments

  - prune\_by\_cs:
    
    Whether or not to ignore single effects not in a reported CS when
    calculating PIP.
