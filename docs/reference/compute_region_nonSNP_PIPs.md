# Computes non-SNP PIPs for all regions from finemapping result

Computes non-SNP PIPs for all regions from finemapping result

## Usage

``` r
compute_region_nonSNP_PIPs(finemap_res, filter_cs = FALSE)
```

## Arguments

  - finemap\_res:
    
    a data frame of finemapping result

  - filter\_cs:
    
    If TRUE, limits to credible sets.

## Value

a vector of non-SNP PIPs for all regions
